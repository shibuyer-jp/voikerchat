## ① キャラクター画像 18枚の生成(T-32 用・最優先)

Gemini の画像生成に以下を貼る。**1キャラずつ生成し、スタイルが揃っているか都度確認しながら進めること**(一括依頼はタッチがばらつきやすい)。

```
日本語学習アプリのキャラクター画像を作ります。以下の共通スタイルを全キャラで厳守してください。

【共通スタイル】
- 明るいアニメ調、クリーンな線画、フラット寄りの彩色
- バストアップ(胸から上)、正面〜やや斜め、笑顔ベース
- 背景は単色(後で透過処理するため白)
- 完全オリジナルキャラクター。既存アニメ・実在人物に似せない
- 正方形構図

【キャラクター一覧】(1枚ずつ順に生成)
1. Sakura — 明るい20代女性、カジュアル服(シーン: 友達)
2. Takuya — 丁寧な若い男性ウェイター、黒エプロン(レストラン)
3. Yumi — 親しみやすい女性店員(買い物)
4. Kouki — 通勤服の若い男性(電車)
5. Akari — 優しい看護師の女性、パステル色の制服(病院)
6. Kenji — 32歳のビジネスマン、スーツ(自己紹介)
7. Minato — 落ち着いたバリスタ男性、カフェエプロン(カフェ)
8. Eiko — 温かい中年女性の先生(フリートーク)
9. Raiki — 燃えるような逆立った髪の熱血少年(熱血戦闘)
10. Hana — 仲間思いの元気な少女(友情協力)
11. Luna — 感受性豊かな涙もろい少女(感動涙)
12. Taro — 学生服の男子生徒(日常学園)
13. Jiro — ひょうきんな表情のコメディアン風男性(ギャグ会話)
14. Haruko — 穏やかな高齢女性、介護施設の利用者(介護のしごと)
15. Dr. Mori — 白衣の落ち着いた医師(医療スタッフ)
16. Sato — スーツの真面目な面接官男性(面接)
17. Mizuki — 役所窓口の丁寧な女性職員(役所・手続き)
18. Tanaka部長 — 50代の貫禄ある上司男性(職場の敬語)
```

生成後の人間側処理(またはClaude Codeに依頼): 白背景の透過化+512×512リサイズ+WebP変換(`cwebp -q 80`)→ `assets/characters/scene_01.webp`〜`scene_18.webp` 命名 → Drive へ。

## ② タガログ語 ARB の校正(品質QA)

`lib/l10n/app_fil.arb` を添付して:
```
これは日本語学習アプリのタガログ語UI文言です。ネイティブのフィリピン人(20〜40代、
日本語学習者)にとって自然か校正してください。直訳調・不自然な敬語・英語のままで
良い箇所(IT用語等)を判定し、修正案を「キー / 現状 / 修正案 / 理由」の表で出して
ください。文字数が極端に伸びてUIを壊しそうな訳も指摘してください。
```

App Store / Play の説明文・キーワード(shibuyer-ops templates 参照)を添付して:

```
フィリピン在住・在日フィリピン人の日本語学習者向けアプリのストア掲載文です。
(1) 英語・タガログ語の掲載文のローカライズ品質レビュー、(2) フィリピン市場での
検索キーワード候補(英/タガログ混在の実際の検索行動を考慮)、(3) 競合(AI会話系
学習アプリ)と差別化できる訴求順の提案、をお願いします。誇大表現(unlimited等)は
使わないこと。
```
