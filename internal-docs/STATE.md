- Premium 解錠がクライアント側のシーンロックに反映されない [判定: 2026-09-10][種別: 判断][優先: 要調査]
  本番DBで `rate_limits.is_premium = true` を直接設定すると、ヘッダーの Pro バッジ・メッセージ上限(50)・Stats へのアクセス(403回避)は正しく反映されるが、**シーン一覧の鍵アイコンだけが外れない**。iPhone 16 Pro Max / iPad Pro 13-inch / Android エミュレータの**3端末すべてで再現**。アプリの完全終了→再起動・ホットリスタート(R)・アプリ削除→再インストール後の初回起動のいずれでも解除されなかった(2026-09-01、撮影セッション)。
  仮説: シーンロック判定が `rate_limits.is_premium` ではなく RevenueCat SDK の Entitlement(`Purchases.getCustomerInfo()`)を直接参照している。`internal-docs/reports/premium_state_mismatch_20260807.md`「1. シーンロック判定」が既にこの構造を記録済みで、`lib/screens/scene_selection_screen.dart`(`isPremiumUser` で `isLocked` を決定)← `lib/screens/home_screen.dart`(`_isPremiumUser` ← `RevenueCatService().checkPremiumStatus()`)← `lib/services/revenuecat_service.dart` の経路。DB の `is_premium` からクライアントのシーンゲートへ至る経路は存在しない。
  実ユーザーへの影響: 実際の課金フローでは RevenueCat Entitlement が立つため正しく解錠されると見られるが**未検証**。**確実に言えるのは、今後の撮影・検証で DB 直接操作による Premium 付与が使えないこと**(手順書 §B の前提が崩れる)。
