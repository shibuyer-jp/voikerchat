# TRIGGERS.md — イベント駆動の実行リスト(2026-08-17新設)

**役割**: 「何が起きたら、何をするか」のみを持つ。日付が読めない項目の受け皿。
`internal-docs/STATE.md`のバックログ(日付駆動、`[判定: YYYY-MM-DD]`形式)とは
**排他的に使い分ける**。日付が決まるならSTATE.md、イベント待ちなら本書。
STATE.mdとの境界: STATE.mdは「いつやるか」が分かっている項目、本書は
「いつになるか分からないが、これが起きたらやる」項目。同じ事実を両方に
書かない。

**更新タイミング**: 項目追加は随時(チャット側Claude・CCのいずれも追加してよい)。
イベント発生時に該当節を実行し、**完了した節は削除して`internal-docs/DECISIONS.md`
へ結果を記録する**。
