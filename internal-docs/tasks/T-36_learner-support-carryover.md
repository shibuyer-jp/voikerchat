# T-36: 学習サポート機能の移植(Web版で実装済み・Flutter化で抜け落ちた分)

## 背景(事実・トレーサビリティ)
前身の Web 版「Japanese Learning App」仕様書 v1.9(2026-06-12)では以下が**実装完了**していたが、
Voikerchat(Flutter)への作り直し時に移植されなかったことを 2026-07-16 のコード監査で確認:
- ふりがな併記(漢字(かんじ)形式) — grep で不存在を確認
- ?hint / ?help(次に何を言えばいいかのヒント) — 不存在
- 単語まとめ(セッション終了時に会話から単語を自動抽出) — 不存在
- ダブルタップ単語質問(?what) — 不存在 → **T-31 で範囲選択方式として仕様化済み**(本タスクの対象外)
※ `tts_text_cleaner.dart` に 'Score: X/10' 除去の残骸があるのは Web 版プロンプトの名残(現行 api/chat.ts に採点出力はない)。

## スコープ(リリース前に入れる3点)
### 1. ふりがな表示(トグル)
- api/chat.ts のシステムプロンプトに「全漢字にふりがなを 漢字(かんじ) 形式で付与」を指示(Web版と同方式)
- 設定画面にトグル「ふりがな表示」(デフォルトON。初級ターゲットのため)。OFF時はプロンプトから指示を外す
- **TTS必須対応**: `tts_text_cleaner.dart` に `漢字(かんじ)` パターンの括弧内除去を追加(Web版でも「ふりがな重複除去」を実施していた。怠ると読み上げが二重になる)。クラウドTTS(T-35)側でも同クリーナーを共用
- 表示品質に欲が出たら将来 ruby タグ描画へ(今回はプレーンテキスト方式で十分)

### 2. ヒントボタン
- チャット入力欄付近に電球アイコン。タップ → 「今の流れで次に言えそうな日本語の例文+英訳」を1つ返す軽量API呼び出し(`mode: "hint"`、T-31 の define と同じ拡張パターンで api/chat.ts に追加)
- 会話クォータは消費しない。ただし辞書(T-31)と合算の軽い日次上限をサーバー側に設定
- usage_logs metadata `{ feature: "hint" }` を記録(オンボーディングの `recordHintUsage` とは別物なので命名衝突に注意)

### 3. 単語まとめ(セッション終了時)
- チャット画面から戻る/リスタート時に「今日の単語」ボトムシート: 直近の会話ログから重要語を最大8個、語+読み+英訳で表示(Web版と同仕様)
- 実装: 会話終了時に1回だけ `mode: "vocab_summary"` でAI抽出(クライアント側の形態素解析は導入しない)
- 将来の拡張(保存・復習リスト化)は Phase 2 バックログへ

## スコープ外(internal-docs/tasks/BACKLOG-Phase2.md へ)
スコアバッジ(10点採点)、文法フィードバックレポート、EN質問モード、リアルタイム音声(Gemini Live)、発音採点、カメラ機能

## 受け入れ基準
- ふりがなON時: 表示にふりがなが付き、読み上げ(端末TTS/クラウドTTS両方)が二重にならない
- ヒント: タップから2秒以内(目安)に例文が出て、そのまま会話を続けられる
- 単語まとめ: 3往復以上の会話終了時に単語リストが表示される(0〜2往復ならスキップ)
- ARB 3言語対応 / `flutter analyze` / `flutter test` 緑
