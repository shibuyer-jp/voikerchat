## 観点別の比較結果

### 観点1: 対象ユーザーの表現 — ★ズレあり(唯一の実質的な相違)

| 媒体 | 対象ユーザーの表現 |
|------|--------------------|
| トップページ タグライン | **`for Filipino Spouses`(フィリピン人配偶者向け)** |
| ストア app 名 | `Voikerchat - Speak Japanese` |
| ストア 短い説明(en) | `... Daily conversation practice for JLPT N5-N4.`(学習者一般) |
| ストア 詳細説明(en) | `built for Filipino learners` / `tuned for Filipino speakers` |
| ストア 詳細説明の実シーン | 介護(kaigo)、申し送り、**特定技能(tokutei ginou)の面接**、役所手続き、職場敬語 |

- トップページだけが対象を **「配偶者(spouses)」に限定**している。ストア掲載情報・
  シーン構成・`GROWTH_PLAN.md` の ASO 方針はいずれも「日本で働く・暮らすフィリピン人
  学習者」全般(特に特定技能・介護の就労者)を対象にしており、「配偶者」という限定は
  どこにも出てこない。
- `for Filipino Spouses` は旧コンセプト(結婚移住者向け日本語アプリ)の名残と見られる。
  現在の製品ポジショニングと矛盾しており、**意図的な限定ではないと考えられる**。
- 実害の程度: voikerchat.com は現状 ASO 対象でも主要導線でもなく流入は少ないと推測される。
  ただし公開済みの公開ページであり、特定技能・介護の就労者が見ると「自分向けではない」
  と誤読する文言が出ている状態。配信停止等のリスクはない。

### 観点2: アプリ名の表記 — 軽微なズレ

- トップページ: h1 は `Voikerchat` 単独、`<title>` は `Voikerchat - Japanese Learning App`。
- ストア: `Voikerchat - Speak Japanese`(app 名の唯一の正、v1.5)。
- トップページの2箇所いずれもストア app 名と一致しない。`<title>` は3つ目の別バリアント。
- トップページは ASO 面ではないため厳密な一致は不要だが、"Speak Japanese" という
  ポジショニング語がトップページに一度も出てこない。

### 観点3: 機能面の訴求がトップページに無い — 欠落(おそらく意図的)

- ヒントボタン・タップ辞書・全漢字ふりがな・18シーン・AI キャラクター会話・
  無料/プレミアムのいずれもトップページに記載がない。
- これは「最小の法務ページ」という現在の役割からくる欠落であり、矛盾ではない。
  トップページを製品ランディングにするかどうかは別の意思決定
  (STATE.md「shibuyer.jp リデザイン」項目は会社ハブの話であり voikerchat.com とは別。
  ただし関連はする)。

### 観点4: 片方だけにある要素

| トップページのみ | ストアのみ |

| 特定商取引法に基づく表記へのリンク(日本の商取引法上の要請。ストアには不要) | 製品/機能の訴求全般、価格モデル、AI 生成コンテンツの断り書き、対象年齢「18歳以上」の明記 |

  あわせて「情報が古いまま止まっている」印象を補強している。
- 矛盾(片方が主張し片方が否定している)は観点1以外に発見されなかった。残りはすべて
  トップページ側の欠落。

## ズレがあった項目の一覧

1. **対象ユーザー**: トップページ `for Filipino Spouses` vs ストア「フィリピン人学習者
   全般(就労者中心)」。実質的なズレ。
2. **アプリ名表記**: トップページ `Voikerchat` / `Voikerchat - Japanese Learning App`
   vs ストア `Voikerchat - Speak Japanese`。軽微。
3. (欠落)機能訴求・価格・AI 断り書きがトップページに無い。矛盾ではなく欠落。

## 補足: `<html lang="ja">` と英語コンテンツの不一致

`docs/index.html` は `lang="ja"` を宣言しているが可視テキストは英語。主要読者が
フィリピン(英語)であることを踏まえると `lang="en"` が正しい。項目1を直す際に
あわせて修正する候補(スクリーンリーダー・翻訳ツールの挙動に関わる軽微な是正)。
