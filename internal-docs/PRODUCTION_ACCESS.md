## 2. 申請の具体手順(Play Console画面遷移)

**[要確認] 以下はGoogle Playの一般的な公開情報をもとにした想定フローであり、現在のPlay Console実画面の文言・階層とは異なる可能性がある。申請開始前に必ずTakatohが実画面で確認し、本書を実際の画面に合わせて修正すること。**

1. **[要確認]** Play Console → 対象アプリ(Voikerchat)選択 → 左メニュー「テストとリリース」配下、または「公開の概要(Publishing overview)」に製品版アクセス申請の導線があるはず
2. **[要確認]** クローズドテストの完走要件(テスター数・継続日数)を満たすと、申請可能になった旨のバナーまたは通知が表示される想定。表示されない場合は「テストの概要」画面でテスター数・オプトイン継続日数の実測値を確認する
3. **[要確認]** 「製品版へのアクセスをリクエスト」等のボタンから申請フォームへ進む
4. フォーム内で以下のような設問に回答する想定(実際の設問文言は**[要確認]**、下記3節に回答案を用意):
   - テストの概要(何をテストしたか)
   - テスターからのフィードバックとその反映内容
   - アプリの品質・安定性に関する説明
5. **[要確認]** 送信後の画面表示(受理番号・審査中ステータスの見え方)
6. 送信完了後、`internal-docs/STATE.md`の「未完了項目」5番を完了に更新し、`internal-docs/DECISIONS.md`に申請日時・回答内容の要約を記録すること(CCが実施)
