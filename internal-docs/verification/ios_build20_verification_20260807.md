# iOS 1.0.0+20 実機検証手順(2026-08-07)

対象ビルド: iOS 1.0.0+20(iOS 26.5.2 / iPhone 16、TestFlight配信)

1.0.0+20は「2026-08-07に発見したPremium判定のクライアント/サーバー
不整合の修正(`api/premium-sync.ts`)」の検証が主目的。詳細は
`internal-docs/reports/premium_state_mismatch_20260807.md`参照。

## 最重要検証(今回の修正の効果確認)

**前提**: アプリを削除し、1.0.0+20を新規インストールすること。
**上書きアップデートでは匿名user_idが変わらず、不整合を再現できない**
(既存の匿名セッションがそのまま引き継がれるため、修正前から
`rate_limits.is_premium`が正しい値のままの可能性が高く、検証にならない)。

| # | 手順 | 期待結果 |
|---|---|---|
| A1 | アプリ削除 → +20を新規インストール → 起動 | 起動できる |
| A2 | 起動後、シーン一覧を確認 | Premiumシーンが解放されている(RevenueCatが購読を復元) |
| A3 | チャット画面で残数表示を確認 | **「50回」等のPremium表記になっている**(修正前は「10/10」だった) |
| A4 | 広告視聴の案内を確認 | **表示されない**(修正前は表示されていた) |

A3・A4が修正前と変わっていなければ、premium-syncが機能していない。
その場合はVercelのログ(`api/premium-sync`)を確認すること。

## 未検証のまま残っている項目

- **購入直後のPremiumシーン即時解除(PR #53)**。TestFlight環境では
  未購入状態を作れないため実施できていない(2026-08-07、SANDBOX APPLE
  ACCOUNTに別アカウントでサインインしても購入は元のApple IDに紐づいた
  ままであることを確認済み)。A1で新規インストールした際に未購入状態に
  なっていれば実施可能
