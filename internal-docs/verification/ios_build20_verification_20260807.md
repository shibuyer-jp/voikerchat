# iOS 1.0.0+20 実機検証手順(2026-08-07)

対象ビルド: iOS 1.0.0+20(iOS 26.5.2 / iPhone 16、TestFlight配信)

1.0.0+20は「2026-08-07に発見したPremium判定のクライアント/サーバー
不整合の修正(`api/premium-sync.ts`)」の検証が主目的。詳細は
`internal-docs/reports/premium_state_mismatch_20260807.md`参照。

## 結果サマリ [検証済 2026-08-07、iPhone 16 / iOS 26.5.2、TestFlight]

**最重要検証(A1〜A4)はすべて期待どおり(オールクリア)**。
`api/premium-sync.ts`による再照合が正しく機能し、再インストール時の
クライアント/サーバー間Premium判定不整合が解消されたことを実機で確認した。
詳細は`internal-docs/STATE.md`未完了項目17参照。

## 最重要検証(今回の修正の効果確認)

**前提**: アプリを削除し、1.0.0+20を新規インストールすること。
**上書きアップデートでは匿名user_idが変わらず、不整合を再現できない**
(既存の匿名セッションがそのまま引き継がれるため、修正前から
`rate_limits.is_premium`が正しい値のままの可能性が高く、検証にならない)。

| # | 手順 | 期待結果 | 結果 |
|---|---|---|---|
| A1 | アプリ削除 → +20を新規インストール → 起動 | 起動できる | ✅ 正常に起動 |
| A2 | 起動後、シーン一覧を確認 | Premiumシーンが解放されている(RevenueCatが購読を復元) | ✅ 解放されている |
| A3 | チャット画面で残数表示を確認 | **「50回」等のPremium表記になっている**(修正前は「10/10」だった) | ✅ 「50回」のPremium表記(+19では「10/10」だった) |
| A4 | 広告視聴の案内を確認 | **表示されない**(修正前は表示されていた) | ✅ 表示されない(+19では表示されていた) |

A3・A4が修正前と変わっていなければ、premium-syncが機能していない。
その場合はVercelのログ(`api/premium-sync`)を確認すること。

## 未検証のまま残っている項目

- **購入直後のPremiumシーン即時解除(PR #53)**。+20でもRevenueCatが
  購読を復元したため未購入状態を作れず、実施できなかった(2026-08-07、
  SANDBOX APPLE ACCOUNTに別アカウントでサインインしても購入は元の
  Apple IDに紐づいたままであることを確認済み)。TestFlight環境で
  これ以上未購入状態を作る手段が無いため、**実機での直接検証は諦め、
  コードレビューによる確認に留める方針とする**。根拠: Androidで同一症状
  (購入後もPremiumシーンが解除されない)が再現しPR #53で修正済み、
  iOS +17でも同一症状を確認済みであり、プラットフォーム固有の問題では
  なく共通コードパスの不具合だったことが確定している
