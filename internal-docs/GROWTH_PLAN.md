# GROWTH_PLAN.md — Voikerchat 販促方針(2026-08-10新設)

公開後の集客・販促の優先順位を記録する。`internal-docs/Competitor-Insights.md`
2026-08-10追補の調査を踏まえ、Takatohがチャット側Claudeと検討した結果。

## 前提: `shibuyer-ops/sns_playbook.md` は流用できない

`shibuyer-ops/sns_playbook.md`(SNSショート動画運用プレイブックv1.0)は
**Tokyo Bible(2026-07に終売決定済み)向け**の内容であり、Voikerchatには
そのまま流用できない。TikTok中心・英語のみ・インバウンド観光客向けという
前提がVoikerchat(日本語学習アプリ・在日フィリピン人向け)と一致しない。
**内容は陳腐化している**。

- プラットフォーム: TikTok+Instagram Reels(観光客向けの動画消費行動が前提)
- 言語: 英語のみ(顧客=インバウンド観光客)
- コンテンツ: 東京の飲食店・ストリートウェア・ナイトライフスポット紹介

Voikerchatのターゲット(在日フィリピン人の日本語学習者、将来的にはB2B/機関向け)
とはプラットフォーム・言語・コンテンツのいずれも異なるため、**新たに本方針を
策定する**。`shibuyer-ops`リポジトリ側のファイル自体は本ドキュメントの対象外
とし、変更しない。

## 優先順位: SNSより先に効くものが2つある

結論として、SNSでの集客に着手する前に、コストが低く効果が見込める2つの
施策を優先する。

### 第1位: ストア掲載情報の最適化(ASO、公開前)

アプリの流入の大半はストア内検索であり、SNSで100人に届けるよりストア検索で
見つかる状態にするほうが安く効く。

- 要点: タイトル・短い説明に、フィリピン人学習者が実際に検索する語
  (Japanese / Nihongo / Tagalog 等)が入っているか
- **`internal-docs/ROADMAP.md`区分3にあった「PR #20 ストアコピペ反映」は、
  実質このASO作業に該当するため区分2(本番アクセス申請までにクリア)へ
  格上げした**(重複タスクとして扱わない、下記「タスク4」参照)
- **`internal-docs/Competitor-Insights.md` 2026-07(初版)の実装ロードマップ案
  項目4「ストア説明文・スクショに『分からない時はヒント/辞書/ふりがなで安心』
  『介護・面接・役所の実践練習』を明記」と同一の作業である**。7月時点の案と
  8月のこの結論は独立した別タスクではなく、優先度付けが揃っただけで内容は
  一貫している

### 第2位: 公開初日のレビュー獲得

- ストアのランキングは初期のレビュー数と速度に強く影響される[一般論、要検証]
- 配偶者経由の実テスター(クローズドテストに参加した16名)は、公開日に
  レビュー投稿を依頼できる唯一の集団である。新規流入100人より初日の★4〜5が
  15件のほうがランキング上効く可能性が高い
- **公開日確定後、配偶者経由で事前に声をかけておく**ことをタスクとして記録する
  (`internal-docs/ROADMAP.md`区分2参照)

### 第3位: Facebook(ここで初めてSNS)

- フィリピン向けならFacebookが主戦場。TikTok/Instagram/Xではない。フィリピンでの
  Facebook利用率の高さと、**在日フィリピン人コミュニティグループがFacebook上に
  多数存在する**ことが理由。[未検証・一般認識ベース]
- **注意**: この種のグループは宣伝投稿に厳しく、直接的な売り込みは削除・追放の
  対象になる。配偶者のネットワークを通じて当事者として紹介してもらう形が現実的

## やらないこと

- **複数プラットフォームの同時運用**。個人開発で公開直後の不具合対応をしながら
  TikTok/Instagram/Xを回すのは不可能
- **放置されたアカウントは無いより悪い**。最終投稿が3ヶ月前のアカウントは
  「このアプリはもう終わっている」という印象を与える。続けられる分だけ作る

## B2Bとの関係(方針の位置づけ)

事業の本命が機関・窓口である以上、SNSの役割はバズではなく
「導入検討時に検索されたとき、活動している形跡があること」に近い。
月1〜2回の更新で「生きている」ことが示せれば目的の大半は果たせる。

## 最小構成

| 施策 | 工数目安 | 時期 |
|---|---|---|
| ストア掲載情報の見直し | 2〜3時間 | 公開前 |
| 既存テスターへのレビュー依頼 | 1時間 | 公開日 |
| Facebookページ開設(更新は月1〜2回) | 2時間 | 公開後 |
| 在日フィリピン人グループへの紹介 | 配偶者次第 | 公開後、様子を見て |
