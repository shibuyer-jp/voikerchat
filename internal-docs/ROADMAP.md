## 3. 一般公開前に済ませたいこと(ハード期限なし)

- **返金時のPremium剥奪の調査**(STATE.md バックログ、2026-08-07新設) —
  **調査完了・原因特定済み(2026-08-10)、修正PR #89作成済み・未マージ**。
  RevenueCatには独立した`REFUND`イベント種別が無く、返金は`CANCELLATION`
  イベントの`cancel_reason='CUSTOMER_SUPPORT'`として届くことを公式ドキュメントで
  確認した。`api/revenuecat-webhook.ts`は現状これを一律no-opとして無視しており
  返金成立後もPremiumが剥奪されない不具合がある。修正はBuild 21が審査中のため
  Build 22以降にまとめて反映する方針でマージを保留している。詳細はSTATE.md
  バックログ・DECISIONS.md 2026-08-10(続4)参照
- **[運用知見、2026-08-10]** RTDN・返金時のPremium剥奪の検証には、
  ライセンステスト購読(更新間隔5分に短縮されるためRENEWAL/EXPIRATION等の
  webhookイベントを短時間で繰り返し発火させられる。実購読では1ヶ月待つ必要が
  あるが、この方法なら数十分で検証サイクルを回せる)を使うと効率的。
  **[2026-08-10追記・要修正]** ただし2026-08-06の開発者本人のライセンステスト
  購読(注文番号`GPA.3366-1618-4848-35600`)はRevenueCat側に記録が見当たらず
  (Active/Expired subscribers=0人、STATE.mdバックログ参照)、**この購読は
  現状このまま検証に使えない**。RTDN接続が完了した現在、Build 21配信後の
  実機Paywall確認時に**新規のライセンステスト購入を行う**ことで、RTDN経由の
  イベント到達を含めて検証サイクルを確立する方針とする
- iOS Sandbox課金検証の残課題(STATE.md未完了項目12) — 購入直後のシーン解除は
  TestFlight環境の制約で実機検証不能のため、コードレビュー確認に留めている。
  公開後、テスターからの同種報告が無いか監視する
- PR #20 ストアコピペ反映(Google Play Console/App Store Connectの該当欄への
  掲載文反映)
- Android署名fail-fast(PR #5、debug鍵フォールバック廃止) — ローカルgradle検証待ち
- 音声のPrivacy開示整合(App Store Connectのプライバシー申告と実装の一致確認)
- 上限到達時に「次に使えるまでの残り時間」を表示(改善候補・優先: 高)
- usage_logs の記録漏れ対応(session_id / tts.tsのmodel / アップセル系イベント)
- release_verification_session_20260726.md の残タスク(STEP2/4/5、Phase D/E) —
  テスト完走後、実機での破壊的操作を伴う検証
